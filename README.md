# 🏠 Airbnb Listings Dashboard (2016)

This project visualizes insights from the **[Airbnb Listings 2016 Dataset](https://www.kaggle.com/datasets/alexanderfreberg/airbnb-listings-2016-dataset)** using Tableau.  
The dashboard provides a detailed view of pricing trends across bedrooms, zip codes, and time.

---

## 📊 Dashboard Overview

🔗 **[View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/srishankar.lokanath/viz/Airbnb_17589692304070/Dashboard1?publish=yes)**  

![Dashboard Screenshot](Dashboard%201.png)

### Key Insights:
1. **Avg Price Per Bedroom**  
   - Price increases significantly as the number of bedrooms increases.  
   - For example, 1-bedroom listings average **$96.2**, while 6-bedroom listings average **$584.0**.  

2. **Distinct Count of Bedroom Listings**  
   - Most listings are **1-bedroom (1,811)** followed by **2-bedroom (483)**.  

3. **Price Per Zipcode**  
   - Geographic distribution of prices across Seattle zip codes.  
   - Some neighborhoods consistently have higher average prices.  

4. **Price By Zipcode (Bar Chart)**  
   - Zip code **98101** has the highest average price among all.  

5. **Revenue For Year (2016)**  
   - Shows a steady increase in revenue throughout the year, crossing **$2M** by December.
